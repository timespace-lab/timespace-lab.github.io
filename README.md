# 시공간 LAB 개편 (2026-10-20)

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전체 (기존처럼 한 파일, 바닐라 JS). 기존 `assets-2an/` 사진 폴더 옆에 두면 됩니다. |
| `config.example.js` | 계정 저장 설정 예시. `config.js`로 복사해 값을 채우면 로그인·계정 저장이 켜집니다. |
| `supabase/schema.sql` | DB 표, 행 수준 보안(RLS), 사진 버킷과 권한 정책. Supabase SQL Editor에서 한 번 실행. |
| `src/` | `index.html`을 만드는 원본 조각. `python3 build.py`로 다시 묶습니다. |
| `test/` | 헤드리스 브라우저 테스트(`t1_local.py`, `t2_cloud.py`)와 테스트용 가짜 Supabase. |

## 기존 코드 분석 요약

- 구조: 단일 HTML, 바닐라 JS, `data-act` 이벤트 위임, 상태가 바뀌면 화면 전체를 다시 그림. 이 구조는 그대로 유지했습니다.
- 실제로 동작하지 않던 것: 저장 표시(항상 "저장됨"), 다시 시도(가짜 타이머), Google 로그인 버튼, 공유 링크(고정 주소), 내보내기(토스트만), 내 탐구·템플릿 화면, 수정·핀 이름 바꾸기·관계 잇기·출처 추가 버튼.
- 지도: 단순화한 해안선 SVG(타일 없음). 경로는 사건 날짜 순서로 자동으로 그려졌음 → 새 요구사항(경로는 별도 데이터)과 충돌.
- 사진: FileReader로 읽은 data URL을 메모리에만 보관(새로고침 시 사라짐).
- 저장: 전혀 없음. 그래서 옮겨야 할 기존 사용자 데이터는 없습니다. 그래도 옛 시안 형식(`events[].p` + `places`)을 읽으면 새 형식으로 바꾸는 변환 함수(`migrateWS`)를 넣었습니다.

## 주요 변경

**유지한 것**: 색상 토큰(Atlas Ivory·Deep Ink·Field Teal·Time Brass), Noto Sans KR, Lucide 선형 아이콘, 버튼·세그먼트·패널 형태, 홈 화면(관측판·두 좌표 표본·세 가지 보기·사진 띠), 왼쪽 레일 + 오른쪽 패널 구성, 시간 좌표/공간 좌표 블록, 박물관형 시간축, 단계 보기, 복습, 관계 보기, 삭제 확인 + 되돌리기, ←→ 키 이동, 반응형 규칙.

**뺀 것**: 오른쪽 아래 "시안 흐름" 단계 버튼. 제품 화면이 아니었고, 누르면 작업을 예시 데이터로 덮어써서 실제 앱에서는 데이터 손실 원인이 됩니다.

**지도 (나의 지도)**
- MapLibre GL 5.2 + OpenFreeMap Positron 벡터 지도(밝은 회색 계열, 지명은 한국어 이름 우선). 확대·축소·이동, 지도 클릭/터치로 핀 추가, 장소 검색(OpenStreetMap Nominatim, 검색 버튼을 누를 때만 호출·1초 간격).
- 홈의 관측판(어두운 지도)·표본 지도·보기 소개 지도, 사건 패널의 작은 지도, 내보내기 미리보기와 PDF·PNG 속 지도까지 모두 같은 실제 지도를 씁니다.
- 지도 라이브러리나 지도 데이터를 못 받거나 WebGL이 꺼진 기기에서는 기존 아틀라스 지도로 자동 대체하고 그 사실을 화면에 알립니다.
- 핀: ID, 좌표, 제목, 장소명, 설명, 날짜·시기(선택), 사진+사진 설명+사진 출처, 출처, 색, 만든/고친 시각. 수정, 위치 옮기기, 삭제(되돌리기).
- 같은 자리 핀: 겹원+개수로 표시하고, 누르면 그 자리의 기록 목록에서 골라요.
- 경로: 핀과 별도 데이터(`routes[].pinIds`에 핀 ID를 순서대로). 경로 설정 모드에서 핀을 차례로 누르거나 목록에서 골라 넣고, 순서 올리기·내리기·빼기, 이름·설명·색·표시 여부. 핀을 고르면 그 핀이 든 경로가 강조되고 나머지는 흐려집니다. 핀을 지우면 경로에서는 그 핀만 빠집니다.

**연표 (나의 연표)**
- 사건: ID, 사건명, 연·월·일(아는 만큼), 기원전, '약' 표시, 날짜 미상, 설명, 사진+설명+출처, 관련 장소, 메모, 만든/고친 시각. 없는 날짜(2월 31일 등)는 막습니다.
- 정렬: 날짜순. 같은 날짜(또는 날짜 미상)끼리는 '앞으로/뒤로'로 순서를 바꿀 수 있습니다. 날짜가 다른 사건을 날짜와 반대로 놓는 기능은 넣지 않았습니다(연표의 시간 의미가 깨지므로).
- 디자인 1 박물관형: 가로 실제 간격 시간축, 큰 연도, 사진·제목·짧은 설명 카드, 사건 사이 간격 표시("약 2개월 뒤"), 가로 스크롤과 앞/뒤 버튼.
- 디자인 2 기록 카드형: 세로 시간축, 연도별 구분, 사진과 긴 설명을 넉넉히, 사진 비율을 자르지 않음(contain), 관계를 카드 오른쪽 곡선으로 표시.
- 디자인은 연표 데이터의 `design` 값 하나만 바꿉니다. 사건·관계 데이터는 건드리지 않습니다.

**사진**
- 기기에서 고르면 바로 미리보기. 25MB 초과·사진 아닌 파일·브라우저가 못 여는 형식(예: 크롬의 HEIC)은 이유를 알려 주고 거부.
- 긴 변 1600px, 약 1.2MB 이하 JPEG로 줄여 IndexedDB에 Blob으로 보관(localStorage에는 사진을 넣지 않음).
- 계정 저장 시 Supabase Storage `<사용자 id>/<사진 id>.jpg`로 올리고 DB에는 경로만 기록. 쓰지 않는 사진 Blob은 다음 실행 때 정리.

**지도와 연표 연결**
- 둘은 따로 저장되는 독립 탐구입니다. 사건은 지도 핀을 `pinId`로 참조할 수 있고, 연표만 따로 저장·공유해도 위치가 남도록 장소 사본(`place`)도 함께 가집니다.
- 연표 사건 → '지도에서 보기', 핀이 없는 장소 → '나의 지도에 핀으로 추가', 지도 핀 → '이 핀으로 연표 사건 만들기'. 지도 화면 아래의 기존 시간축과 선택 연동은 그대로입니다.

**저장 정책**
- 로그인 없이: 모든 편집이 0.35초 안에 이 기기(IndexedDB)에 저장되고, 새로고침·재방문 때 복구됩니다. 창을 닫는 순간을 대비해 글자 데이터만 localStorage에 비상 사본을 둡니다.
- 상단에 두 상태를 따로 표시: "이 기기에 임시 저장됨 · 시각" | "계정에 저장됨 / 저장 안 된 변경 있음 / 계정 저장 실패 / 미설정". 계정 저장이 성공했을 때만 "계정에 저장됨"이 뜹니다.
- '나의 지도로 저장'·'나의 연표로 저장' → 로그인 안 했으면 로그인 창. 로그인하고 돌아오면 누르던 저장을 이어서 합니다. 취소·실패해도 작업은 그대로입니다.
- 중복 클릭 무시, 네트워크 오류·로그인 만료 시 실패 배너와 다시 시도, 다른 기기에서 먼저 저장한 경우(버전 충돌) 덮어쓰기/따로 저장 선택.
- 내 탐구: 계정에 저장한 지도·연표 목록, 불러오기(저장 안 된 변경이 있으면 확인 후, 직후 되돌리기 가능), 계정에서 지우기.

**공유·내보내기 (미완성이던 기능 보완)**
- 공유: 계정에 저장한 탐구만. 끄기/보기만/복사 허용. 링크를 연 사람은 로그인 없이 보기 전용으로 보고, 받은 사람 기기의 작업과 섞이지 않습니다. 복사 허용이면 '내 기기로 가져오기'.
- 내보내기: PDF(A4 가로/세로) 또는 PNG, 지도/연표/둘 다, 설명·사진·출처 목록 선택. 지도는 화면 밖에서 실제 지도를 그려 캔버스로 옮기고(실패 시 해안선 지도), 연표는 고른 디자인 그대로 그린 뒤 카드 경계에서만 쪽을 나눕니다. 도구(html2canvas·jsPDF, cdnjs)를 못 받으면 '도구 없이 지도만 PNG로 받기'를 제공합니다.

## 필요한 환경 설정 (계정 저장을 켜려면)

지금 연결된 Supabase 계정의 `thinklink` 프로젝트는 다른 앱(생각이음)의 실제 학생 데이터가 들어 있어 **아무것도 바꾸지 않았습니다.** 시공간 LAB용으로는 새 프로젝트를 쓰는 것을 권합니다(같은 프로젝트를 써도 이름이 모두 `sg_`로 시작해 겹치지는 않습니다).

1. Supabase 프로젝트를 만들고 SQL Editor에서 `supabase/schema.sql`을 실행합니다.
2. Authentication → URL Configuration: Site URL과 Redirect URLs에 앱 주소를 넣습니다(예: `https://<아이디>.github.io/<저장소>/index.html`, 그리고 개발용 주소).
3. Google 로그인: Google Cloud Console에서 OAuth 클라이언트(웹)를 만들고, 승인된 리디렉션 URI에 `https://<프로젝트>.supabase.co/auth/v1/callback`을 넣은 뒤, Supabase → Authentication → Providers → Google에 클라이언트 ID·보안 비밀을 넣습니다. 이메일 로그인 링크는 기본으로 켜져 있습니다(대량 발송 시 SMTP 설정 권장).
4. `config.example.js`를 `config.js`로 복사해 Project URL과 publishable(anon) 키를 넣고 `index.html` 옆에 둡니다. 비밀 키(service_role)는 절대 넣지 마세요.

지도 관련 이용 조건
- OpenFreeMap 공개 서버는 가입·API 키 없이 쓸 수 있고 지도 조회 수 제한이 없으며, 출처 표시가 필수입니다(지도 오른쪽 아래에 자동 표시, 내보낸 파일에도 들어감). 다른 지도 스타일을 쓰려면 `config.js`에 `mapStyle`(MapLibre 스타일 주소)을 넣으세요.
- 구글 지도는 API 키·결제 등록이 필요하고, 구글 지도 그림을 다른 지도 엔진에서 쓰는 것을 약관이 허용하지 않아 쓰지 않았습니다.
- Nominatim은 초당 1회 이하, 자동완성 금지 정책이 있어 검색 버튼을 누를 때만 호출합니다.

## 미완성·확인하지 못한 항목

- **실제 지도 타일·Leaflet·장소 검색·PDF/PNG 파일 생성은 실제 브라우저에서 확인하지 못했습니다.** 작업 환경에서 CDN·타일 서버 접근이 막혀 있었고, 테스트는 대체 아틀라스 지도로 진행됐습니다. 배포 후 지도 화면, 장소 검색, 내보내기 한 번씩 확인이 필요합니다.
- **실제 Supabase·Google 로그인은 연결해 보지 못했습니다.** 위 설정을 마친 뒤 로그인→저장→다른 기기에서 불러오기→공유 링크를 한 번 확인해 주세요.
- 디자인 2의 관계 선은 카드 오른쪽 여백에 그리므로, 아주 좁은 화면에서는 일부가 화면 밖으로 나갈 수 있습니다.
- 보기 모드의 '연결 보기'는 기존 시안처럼 비활성으로 남겨 두었습니다.
- 템플릿 화면은 따로 만들지 않고 '예시 탐구 열어 보기'로 대신했습니다.
